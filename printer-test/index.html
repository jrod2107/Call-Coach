Label printer test

A temporary page to check whether a phone can print to a Bluetooth label printer straight from a web page. It holds no customer data and saves nothing.

Before you start

1. Use Chrome on an Android phone. Other browsers, and iPhones, cannot do this.

2. Turn the printer on, with a 4x6 label roll loaded. Turn on Bluetooth and Location on the phone.

3. Close the printer's own app, because it can hold the printer's Bluetooth connection.

Step 1: Connect

Pick the printer (its name may start with Labeer or Y43, or show only as letters and numbers) from the list Chrome shows.
